# B2-1 동료평가 대비 가이드

## 1. 이 과제가 뭔가요?
Python으로 용돈 기입장 프로그램을 만들고 Git으로 관리하는 과제.

## 2. 평가 예상 질문
Q1. 데이터 저장 방식 선택?
A. JSONL 선택 — 구조화된 데이터, 확장성, 한 줄씩 append 가능.

Q2. 예외 처리 방식?
A. try/except로 에러를 잡고 사용자 친화적 메시지 출력. 스택트레이스 출력 금지.

Q3. CRUD 구조?
A. Create(입력), Read(조회), Update(수정), Delete(삭제) — 데이터 관리의 기본 패턴.

Q4. Git 브랜치 전략?
A. 기능별 브랜치 → merge. commit 메시지로 변경 이력 관리.

Q5. 외부 라이브러리 금지 영향?
A. 표준 라이브러리만 사용 — 기본기 점검, 의존성 최소화.
